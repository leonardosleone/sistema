Configurar Firebase
Para sincronizar datos entre dispositivos necesitás conectar una base de datos gratuita de Firebase.
📋 Cómo obtener las credenciales ▼
1. Ir a console.firebase.google.com
2. Crear proyecto → nombre libre → deshabilitar Google Analytics → Crear
3. En el panel, hacer clic en el ícono web </> → registrar app → nombre libre → Registrar
4. Copiar los valores del objeto firebaseConfig que aparece
5. Ir a Firestore Database → Crear base de datos → Modo producción → elegir región
6. Ir a Reglas → pegar esto y publicar:
rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /{document=**} { allow read, write: if true; } } }

La configuración se guarda localmente. Solo necesitás configurarlo una vez por dispositivo.
